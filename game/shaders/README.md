# `game/shaders/` — Painterly Pixel-Art & Atmosphere Shaders

Planned Stage 05 Visual Prototype Gate shaders (`docs/concept/14-art-direction-and-pixel-art-bible.md`):
- `palette_lut_grade.gdshader` — Artist-authored 1D Color Grading LUT for Dawn / Sun / Dusk / Bioluminescent Night & Storm shifts.
- `pixel_wind_sway.gdshader` — Pixel-snapped wind animation for Singing Reedwoods, Amber Tide-Kelp, and Wind-Grain Grass.
- `water_reflection.gdshader` — Shallow shoreline foam & twin-moon sky reflection shader.
- `subpixel_camera_overscan.gdshader` — Smooth sub-pixel panning test (`482×272` overscan) for the Windows Visual Prototype Gate (`DDL-011`).
